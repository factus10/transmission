Claude can now help with the audit from inside Transmission. A new ✦ button opens a Claude Code session on the current project — in the Claude app, with the audit skills loaded — and anything Claude suggests comes back as proposals you accept or reject in the app, logged with the reason and undoable in one step. Nothing is written to the audit until you say so. Project files move to a newer format on first open; everyone sharing a project should update together.
