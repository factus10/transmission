# Migrate

## Field Rules

- Status Code is 200
  Page loads successfully — no errors or redirects

- Indexability Status is Indexable
  Search engines can and should index this page

- Word Count > 300
  Substantial content, not a stub or placeholder

- Title 1 is not empty
  Basic SEO hygiene — has a title tag

- Meta Description 1 is not empty
  SERP snippet is present for search results

- H1-1 is not empty
  Has a primary heading for structure and accessibility

- H1-2 is empty
  No duplicate H1 — structurally correct (only one H1)

- Unique Inlinks >= 3
  Well-connected in the site architecture, not orphaned

- No. Near Duplicates is 0
  Unique content — not substantially duplicated elsewhere on the site

- Crawl Depth <= 4
  Accessible within 4 clicks from the homepage

- Spelling Errors <= 2
  Content is polished and professional

- Grammar Errors <= 2
  Content is polished and professional

- Content Type contains text/html
  It's an actual web page, not a file or resource

## Content Rules

- Page provides comprehensive, authoritative coverage of its topic
- Content is well-structured with clear headings and logical flow
- Page serves a clear purpose in the site's information architecture
- Content is current, accurate, and appropriate for the target audience
- Page is not substantially duplicated by another page on the site
