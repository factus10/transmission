# Archive

Each rule below is an independent signal — any one is sufficient to flag a page for removal.

## Field Rules

- Status Code >= 400
  Broken page — 404 not found, 500 server error, etc.

- Word Count < 50
  Empty or near-empty page with no real content

- Unique Inlinks is 0
  Complete orphan — nothing on the site links to this page

- No. Near Duplicates > 2
  Content exists in 3+ other places on the site

- Crawl Depth > 8
  Buried so deep in the site hierarchy it's practically invisible

- Text Ratio < 5
  Almost entirely boilerplate/template markup with negligible unique content

## Content Rules

- Page has no unique value and duplicates content found elsewhere on the site
- Content is severely outdated with no viable update path
- Page serves no clear purpose and has no logical place in the site architecture
- Content is stub-level or placeholder with no meaningful information
- Page is an orphan with no internal links pointing to it and no external traffic
