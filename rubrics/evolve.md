# Evolve

Each rule identifies a specific, fixable problem. A page matching even one has a concrete issue to address.

## Field Rules

- Status Code is 200
  Page is live — there's something to work with

- Indexability Status is Indexable
  Page is indexed, so improvements will have SEO impact

- Word Count >= 50 and Word Count <= 300
  Has some content but thin — needs expansion to be competitive

- Meta Description 1 is empty
  Missing SERP snippet — easy SEO win to add one

- H1-1 is empty
  Missing primary heading — structural fix needed for SEO and accessibility

- H1-2 is not empty
  Multiple H1 tags — needs structural cleanup (should have exactly one)

- Title 1 Length > 60
  Title too long — will truncate in search results

- Meta Description 1 Length > 160
  Description too long — will truncate in search results

- Spelling Errors > 5
  Noticeable content quality issues worth fixing

- Grammar Errors > 5
  Noticeable content quality issues worth fixing

- Flesch Reading Ease Score < 30
  Very difficult to read — may need simplification for the target audience

- No. Near Duplicates >= 1 and No. Near Duplicates <= 2
  Some duplication — candidate for merging with similar pages

- Semantic Similarity Score > 0.85
  High cannibalization risk — this page competes with another for the same queries

- Unique Inlinks >= 1 and Unique Inlinks <= 2
  Weakly linked — needs better internal linking to support discovery

## Content Rules

- Page has a viable topic but content is thin or incomplete
- Content is outdated but could be refreshed to become valuable
- Page could be merged with related pages to create stronger content
- Structure or formatting needs significant improvement for readability
- Page has SEO issues (missing or poor title/description/H1) but the content itself has value
- Content quality is weak (spelling/grammar issues, poor readability) but the topic is worth covering
